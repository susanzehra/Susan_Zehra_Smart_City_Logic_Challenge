# Susan Zehra's Smart City Logic Challenge

A self-contained, interactive browser activity covering:

- CNF and implication removal
- propositional resolution
- proof by refutation
- first-order logic vocabulary
- translating real-world policies into FOL
- quantifier meaning and order

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this project. Keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then save.
6. Wait for GitHub to display the public website address.
7. Replace the placeholder URL in the Canvas lab instructions with that address.

No build process, server, database, password, or API is required. Student names and answers remain in the browser and are not transmitted or stored.

## Instructor verification

Open `index.html` in a browser and complete all seven missions. After the final mission, verify that the certificate displays the entered name and local completion date/time. Test **Print or Save as PDF** before distributing the activity.
